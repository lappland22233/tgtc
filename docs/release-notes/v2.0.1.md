# TGTC v2.0.1 发布说明

本版修复覆盖上传、跨 Bot 文档授权、跨库迁移和告警队列中的数据一致性问题，并将 Linux x86_64 发行包、CI 和手动部署运行时统一到 Node.js 22。发行包内置 Node.js 22.23.5。

## 文件与 Telegram

- 上传源和回执按版本隔离。已有远端回执的失败作业可以继续提交，等待 Telegram 账号名额的作业会让出执行位置。
- 永久删除在数据库事务内核对文件状态。覆盖上传、移动、重命名和撤销授权时保留并发写入的存储引用。
- 账号池按接收 Bot 隔离授权和等待提示。照片、视频在文件转存期间仍会收到格式提示。停机时排空已经扣额的转存，未知长度的文件在写入前申请额外磁盘空间。
- Bot API 在多个下载之间共享磁盘预算，流式请求与普通下载共用同一份文件。工作目录清理保留 webhook 证书。

## 管理、分享与监控

- Google Drive 手动授权和一键授权共用回调。发起授权后使用服务端返回的 `state`，提交授权或重绑账号时传回该值。升级前未完成的授权需重新发起。有账号仍依赖当前应用时，管理页会阻止更换 Client ID。
- 退出或切换账号时清理下载队列。切换分享链接时停止上一分享的音视频。修复 PostgreSQL 密码分享和过期预览会话清理。
- 分钟告警按作业原定时间评估。空闲窗口直接完成，有访问记录且聚合尚未就绪时继续重试。SQLite 的低流量 QPS 保留小数。

## 升级与回退

- 本版包含数据库迁移。新增接收 Bot 身份、一次性 OAuth 状态和 SQLite 分钟指标结构。历史下载链接继续有效，旧版已入队的上传可沿用原交接路径恢复。
- 从 PostgreSQL 转 SQLite 时，可使用包内的 `backend/dist-migrator/build-data-migrator.js`。工具在快照中复制业务数据，遇到未覆盖的非空业务表会中止切换。
- 从旧版升级时，先校验候选包签名，使用候选包随附的升级脚本。升级会先停止写入再备份。本版声明 `programRollbackSafe=false`，迁移后失败时保持停写，恢复匹配的数据库备份后再启用旧程序。[部署文档](../deployment.md)
