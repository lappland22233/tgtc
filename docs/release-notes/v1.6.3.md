# TGTC v1.6.3 发布说明

本版本为**安全维护版**：不引入新功能、不新增数据库迁移，聚焦依赖高危安全漏洞治理、死代码精简及七维度全量审查基线落地。

## 1.6.3 修复与改进

- **后端依赖高危漏洞清零（SEC-101B）**：
  - 升级 `multer` 至 `2.5.0`，修复 `GHSA-q7qp-rjg7-q26m`（请求中断后异步 fileFilter 导致未捕获异常引发 DoS）；
  - 修复 express 内部传递依赖 `proxy-addr`（CVE-2024-52316 / `GHSA-jqcg-44mw-7w3h`，**Critical** 级 IPv4-mapped IPv6 受信任子网伪造绕过）；
  - 修复 `body-parser`（`GHSA-27r3-jxmh-p828` 压缩请求体后 DoS）、`sharp`（`GHSA-wq5f-xc86-pv6w` librsvg CVE-2026-96889）、`undici`（`GHSA-4qv8-2p9j-2685` 等 5 条高危 DoS 与 TLS 绕过）以及 `follow-redirects`（`GHSA-q3jh-wrc6-jgq8` 等凭据泄露绕过）；
  - 后端生产环境高危门禁（`npm audit --omit=dev --audit-level=high`）漏洞数归零。
- **前端 XSS 漏洞修复（SEC-101F）**：
  - 升级 `vue` 至 `3.5.44`，消除 `@vue/server-renderer`（`GHSA-g2v6-rqmx-r4w6` **High**，属性黑名单遗漏 CR 导致的 XSS 漏洞）；
  - 前端生产环境依赖审计（`npm audit --omit=dev --audit-level=high`）实现 `found 0 vulnerabilities`。
- **过度设计与死代码清理（OD-101）**：
  - 经全仓引用分析，安全移除了 3 个业务零引用的遗留 Composable 文件：`useDragMove.ts`、`useFileClipboard.ts`、`useTimeRange.ts`，前端类型与构建保持 0 错误。
- **七维度全量审查基线落定**：
  - 完成了首个覆盖服务端性能（PERF-B）、客户端性能（PERF-F）、安全性（SEC）、用户体验（UX）、运维难度（OPS）、文档可读性（DOC）与过度设计（OD）的完整审查评估，归档至 `.codebuddy/review-report-v1.6.2.md`（综合评分 4.70 / 5.0）。

## 数据库与回退

- **无新增迁移**：本版本仅为依赖升级与死代码清理，继续兼容 180330–180390（PG/SQLite）已落地的结构，不删改旧字段与旧路径。
- 发行包仍携带**完整迁移链**，因此 `RELEASE_INCLUDES_DB_MIGRATION=true`。
- `RELEASE_ROLLBACK_SAFE=false`：迁移链含历史不可逆回填，需按运维文档在确认数据库已恢复到备份快照后方可执行回退。

## 兼容性

- 目标平台：Linux x86_64；运行时 SQLite 默认 / PostgreSQL 双方言。
- 升级路径：1.6.0 及以上版本均可无缝升级。
- 客户端无需变更：API 与前端资源保持向后兼容。
