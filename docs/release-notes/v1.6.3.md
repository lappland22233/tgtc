# TGTC v1.6.3 发布说明

本维护版修复认证、分享预览、账号池文件复制和 IP 解封的一致性问题，并补齐真实数据库回归与本地/CI 共用质量门禁。

- 验证码在匹配及消费前原子执行限流，锁定期间不能通过继续猜测完成密码重置。
- 告警 WebSocket 在建立连接及生命周期复核时复用 HTTP 会话验证，检查 JWT 吊销、密码修改与用户状态。
- 分享预览会话确认与额度扣减在同一事务中完成，兼容 SQLite/PostgreSQL；最后一次访问名额内的同会话 Range/重连可继续，新访客仍被拒绝。
- 文件复制保留来源 Bot、内容稳定身份及消息锚点，并为新逻辑文件复制每个账号已有的 ready 副本，避免使用默认 Bot 下载其他账号的 file_id。
- 分享和文件密码校验尊重管理员解封，自动再次封禁会重新激活封禁记录。
- 更新 NestJS 11、Multer、sharp、Nodemailer、Vue、TDesign 及受影响传递依赖，保留生产依赖高危/严重漏洞阻断，不添加审计忽略项；清理本次扫描发现的全部生产依赖告警。
- SQLite/PostgreSQL 共用业务回归覆盖并发、事务回滚、限次预览、吊销、解封和复制下载；增加真实 Redis 任务生命周期与 HTTP multipart 单文件、多文件、超限、中断清理测试。
- 前后端增加 `npm run check:ci` 并由 CI 调用，统一依赖树、审计、类型、构建和覆盖率检查；前端增加覆盖率下限，保留原有体积门禁。

## 数据库与兼容性

没有新增数据库迁移，继续兼容现有 PostgreSQL/SQLite 结构和 API。版本号在 VERSION、前后端清单及两份锁文件中统一为 1.6.3。

发行包仍包含完整迁移链，`RELEASE_INCLUDES_DB_MIGRATION=true`，从旧版升级前必须备份。既有不可逆回填仍在，`RELEASE_ROLLBACK_SAFE=false`；回退需遵循运维文档的数据库备份恢复流程。安全修复回退后旧漏洞会重新出现。
